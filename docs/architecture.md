## 前端架构 (Frontend)

```
frontend/
├── src/
│   ├── app/                    # Next.js App Router
│   │   ├── layout.tsx          # 根布局组件
│   │   ├── page.tsx            # 首页/播放器主界面
│   │   └── globals.css         # 全局样式
│   │
│   ├── components/             # React 组件
│   │   ├── Player.tsx          # 播放器核心组件
│   │   ├── Playlist.tsx        # 播放列表组件
│   │   ├── Lyrics.tsx          # 歌词显示组件

│   │

│   │   └── playerStore.ts      # 播放器状态管理
│   │
│   ├── utils/                  # 工具函数
```

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端框架 | Next.js 14 | React 全栈框架 |
| UI 库 | React 18 | 组件化 UI |
| 样式 | Tailwind CSS | 原子化 CSS |
| 状态管理 | Zustand | 轻量级状态管理 |
| 后端框架 | Express.js | Node.js Web 框架 |
| 数据库 | MongoDB | NoSQL 数据库 |
| ORM | Mongoose | MongoDB ODM |
| 认证 | JWT | 用户认证 |
| 本地存储 | IndexedDB | 浏览器本地存储 |
